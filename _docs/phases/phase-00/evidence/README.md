# Phase 00 — evidence

Date (UTC): 2026-11-16T17:17:03Z (E20–E28 added later in phase 00)

All items below were run by the executor (Claude Opus 5.5) on 2026-11-16 on the target Mac (Apple Silicon, macOS 27.2.1, Xcode 27.2, Swift 6.4.2, printer `Brother_MFC_J6520DW`, single user `fenma`).

**Important limits.**

- There is no automated test target in the project. E01–E15 were ad hoc Swift harnesses, compiled together with the app's own source files (`CUPSClient.swift`, `PreviewBuilder.swift`, `QueueStore.swift`, `LanguageSettings.swift`) in the session scratch directory and deleted afterwards. They are not in the repository and cannot be re-run as-is.
- E01–E15 were run against the code as it was at that moment; later edits (for example the English translation of messages and the introduction of `JobStatus`) were not re-checked with the same harnesses. The builds and bundle checks in E16 reflect the current code. In particular, E03 and E05 called `PreviewBuilder.makePDFData`, which was later replaced by `makePreview` (each document rendered separately); E22 covers the current function, including several documents.
- The executor has no screen recording or accessibility access: the real window was never seen. Visual and interaction behaviour is therefore not proven (see [practical checks](../../../../_specs/getting-started/validation.md)).
- Sandbox: E04, E06, E07, E20 and E23 ran in a harness app bundle signed with the app's entitlements file (`app-sandbox`, `print`) and hardened runtime; the other harnesses (including E25 and E26) ran without the sandbox.
- No check printed on paper. Test jobs were held (`lp -H hold`) or empty (`Create-Job` without a document) and titled `MPQV …`, and were removed afterwards, including from the completed-job history.
